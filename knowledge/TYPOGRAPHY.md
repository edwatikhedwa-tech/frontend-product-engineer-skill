# Typography

- Choose a readable typeface already available to the project unless a product decision supports adding one.
- Define roles: display, page title, section title, body, label, metadata, code, and numeric data.
- Prefer a small type scale with explicit line heights and weights.
- Keep body and data text readable at the smallest supported viewport.
- Avoid tiny gray secondary text as a substitute for hierarchy.
- Set line lengths appropriate to the content; constrain prose but allow data to breathe.
- Check numerals, tabular data, localization expansion, truncation, wrapping, and mixed scripts.
- Use uppercase sparingly; if used, provide enough tracking and contrast for legibility.

Typography is part of information architecture. Changing font size alone does not repair a weak content model.

# Prompt starters

These are short invocation patterns, not substitutes for the skill’s workflow.

## CREATE

```text
Use $front in CREATE mode. Start with the product job and information architecture, research references by problem, implement a coherent first slice, run the real app, and do not stop before screenshots and the quality gate.
```

## REDESIGN

```text
Use $front in REDESIGN mode. Discover the whole product, run the current app, capture important screens, propose a systemic direction, then implement and independently review the rendered result.
```

## EXTEND

```text
Use $front in EXTEND mode. Preserve the existing visual language and tokens, add the requested feature, test realistic states, and run browser regression checks.
```

## REVIEW

```text
Use $front in REVIEW mode. Do not change code. Judge only the rendered product and report P0/P1/P2/P3 findings with evidence.
```

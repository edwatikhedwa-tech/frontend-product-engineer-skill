# Transformation gate

Use for REDESIGN. CREATE has no BEFORE state, so it uses the Design Director and anti-generic gates instead. EXTEND compares the affected existing surface with the new feature when visual drift is a risk.

## Decision rule

The AFTER result must show meaningful, intentional improvement in the dimensions relevant to the redesign. “Slightly tidier”, changed colors/radius, or a component swap is not enough when the original product is clearly weak. If the original is already strong, preserve what works and explain why transformation is deliberately restrained.

If BEFORE evidence is unavailable, mark the transformation gate unverified; do not invent a comparison. If the redesigned surface is nearly unchanged, either justify preservation with evidence or return to Design Director and revise the direction.

## Evidence

Use matched states and viewports where possible. Record what changed, why it changed, what improved for the user, what intentionally did not change, and any remaining P3 opportunities. A redesign cannot pass on a numeric score alone.
